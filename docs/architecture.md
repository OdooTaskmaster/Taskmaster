# Архитектура реализации (AS-IS)

[README](../README.md) | [Разработка](development.md) | [Проверки](testing.md)

## Состояние каркаса

| Файл | Назначение |
|---|---|
| [`__manifest__.py`](../__manifest__.py) | Объявляет устанавливаемый плагин для Odoo 20.0 с зависимостью от `project`. Файлы данных, фронтенд-ресурсы и внешние Python-зависимости не зарегистрированы. |
| [`__init__.py`](../__init__.py) | Обозначает пакет плагина. Подмодули не импортируются. |
| [`application/`](../application/__init__.py) | Пустой пакет для прикладных сценариев, независимых от ORM, HTTP и очереди. |
| [`adapters/`](../adapters/__init__.py) | Пустой пакет для интеграции прикладного кода с Odoo и другой инфраструктурой. |

Прикладных классов и взаимодействий между ними пока нет. Сценарии агента, чтение и запись данных Odoo, REST и обработка очереди не реализованы. По мере появления кода здесь описываются классы, их ответственность, зависимости и обмен данными.

Целевые решения (TO-BE) хранятся локально в `.private/архитектура/`. Точки входа в эти материалы перечислены в [AGENTS.md](../AGENTS.md).
