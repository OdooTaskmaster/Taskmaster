## Текущее состояние

Модульных тестов и проверенной команды их запуска пока нет. Загрузка нового плагина в Odoo не подтверждена. Команды и результаты проверки прежней реализации к новому коду не относятся.

`TECH-01` фиксирует проверку загрузки каркаса на согласованном стенде, `TECH-02` добавляет воспроизводимый запуск модульных тестов. После выполнения задач здесь указываются проверенные команды, условия запуска и фактические результаты. Для задач без автоматизированной проверки документируйте воспроизводимые ручные шаги из критериев приёмки.

## AG-01: стенд сравнения моделей

Стенд `tools/model_eval/` проверяется без сети и без ключа:

```powershell
python tools/model_eval/run_eval.py --self-test
python -m unittest discover -s tools/model_eval/tests -v
```

Проверено 26.11.2026: self-test проходит, 24 модульных теста проходят. Реальный
прогон моделей требует `ROUTERAI_API_KEY` в `.env` и запускается отдельными
стадиями `probe`, `smoke`, `full`; см. `tools/model_eval/README.md`. Результаты
сравнения 15 моделей — в `tools/model_eval/REPORT.md`, принятое решение — в
`tools/model_eval/DECISION.md`.
