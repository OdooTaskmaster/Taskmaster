## Текущее состояние

Загрузка нового плагина в Odoo не подтверждена. Команды и результаты проверки прежней реализации к новому коду не относятся.

Модульные проверки скрипта подготовки аккаунтов запускаются из корня репозитория на Python 3.12 без подключения к Odoo:

```powershell
python -B -m unittest discover -s tests -p test_pilot_users.py
```

В тестах используется имитация ORM. Они не подтверждают права в Odoo, вход в реальные аккаунты или доступ к проектам; эти проверки выполняются на пилотном стенде.

`TECH-01` фиксирует проверку загрузки каркаса на согласованном стенде, `TECH-02` добавляет воспроизводимый запуск модульных тестов. После выполнения задач здесь указываются проверенные команды, условия запуска и фактические результаты. Для задач без автоматизированной проверки документируйте воспроизводимые ручные шаги из критериев приёмки.
