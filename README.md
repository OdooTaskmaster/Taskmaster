# Project AI Conductor

Project AI Conductor — проект плагина для Odoo Project. Его цель — помочь руководителям и командам вовремя замечать риски, разбирать их по данным Odoo и согласовывать следующие действия в контексте задачи.

## Что должен делать пилот

- Каждое утро автоматически проверять проект и доставлять руководителю сводку рисков в Odoo. Сводка строится по правилам и не зависит от доступности ИИ.
- Показывать проверяемые факты отдельно от объяснения агента со ссылками на разрешённые источники. Не подменять нехватку данных догадкой.
- Готовить черновик комментария. Руководитель проверяет и подтверждает итоговый текст, а исполнитель отвечает в задаче Odoo. Агент не меняет проект и не публикует комментарии самостоятельно.

## Целевая архитектура

Python-ядро работает внутри Odoo как модульный монолит с гексагональными границами. Интерфейс на JavaScript обращается к плагину через REST: быстрые действия выполняются синхронно, для выбранных долгих операций и утренней проверки используется отдельный брокер. ИИ-сценарии оркестрирует LangGraph; модель получает только разрешённый контекст и узкие инструменты чтения. Конкретные версии и инфраструктурные компоненты определяются в соответствующих задачах.

## Состояние репозитория

Прежняя реализация удалена из рабочего дерева и доступна в истории Git. Сейчас в репозитории только подготовительный каркас: рабочие сценарии не реализованы, установка отключена в манифесте, проверенной команды запуска пока нет. Загрузка нового каркаса на пилотном стенде и воспроизводимый запуск модульных тестов входят в задачи `TECH-01` и `TECH-02`.
