## Критерий выбора

1. Контракт: JSON, вызовы инструментов, корректные источники, отсутствие выдуманных фактов.
2. Качество на русском: проверяемые факты, различение факта и сообщения участника, поведение при пробеле в данных.
3. Отказ доступа и сбой источника без утечки и без подмены пустотой.
4. Задержка и цена в пределах пилота.
5. Условия обработки данных и юрисдикция.

## Почему GLM 5.3 Flash

- Максимальный балл среди моделей, доступных в РФ: 98.5 против 93.0 у GigaChat Ultra.
- Единственная слабость — C08 (85): статус `ok` вместо `insufficient_data` при пустых
  данных. Это лечится формулировкой промпта, а не сменой модели.
- Полный контракт: tools и structured output заявлены и проверены вызовом.
- Контекст 262k достаточен для карточки, описания, истории, комментариев и трудозатрат.
- Цена не является ограничением: 5.95 ₽ за 10 кейсов, ~595 ₽ за 1000 прогонов.
- Вендор заявляет обработку без сохранения содержимого запросов (Z.ai DPA).

## Альтернативы

| Вариант | Когда выбирать | Ограничение |
|---|---|---|
| `sber/gigachat-3.5-ultra` | если требуется российская юрисдикция без оговорок | 93.0; пропускает чтение описания, отдаёт факты с пустыми значениями |
| `anthropic/claude-haiku-5.5` | если допустима обработка в США и нужен эталон надёжности | 99.0, но 11.8 s p50 и юрисдикция США |
| `deepseek/deepseek-v4.1-flash-1017` | если нужна максимальная скорость | 96.5, но 14.99 ₽ и политика хранения данных в КНР |
| `mistralai/mistral-large-4-0` | если нужна западноевропейская юрисдикция | в полный прогон не отобран; smoke 95.0 |

Не рекомендованы: `qwen/qwen3.7-flash` (C09 = 30: путает сбой источника с отсутствием
данных), `google/gemini-3.1-flash-lite` (C02 = 50: игнорирует усечение),
`yandex/aliceai-llm-flash` (не вызывает инструменты), `openai/gpt-oss-*` (пустые
значения фактов), `openai/gpt-5-nano` (57 s на кейсе).

## Условия обработки данных

Оценка проводилась через `routerai.ru` — это **только транспорт для сравнения моделей**.
В итоговом плагине RouterAI не используется: подключается официальный провайдер модели
или собственный роутер. Условия ниже относятся к вендорам, а не к RouterAI.

| Вендор | Где обрабатывается | Обучение на данных API | Срок хранения | Вердикт для данных клиник |
|---|---|---|---|---|
| Zhipu / Z.ai (GLM) | Сингапур (Z.ai), Китай (BigModel.cn) | нет, по DPA контент не сохраняется |обработка в реальном времени, без сохранения | допустимо с договором; для РФ-размещения нужен реселлер |
| Sber / Cloud.ru (GigaChat) | РФ | нет | не логируется | допустимо, 152-ФЗ |
| Yandex (Alice) | РФ | нет | по политике | допустимо, но модель не прошла контракт |
| Anthropic (Claude) | США | нет по умолчанию | 30 дней | только при согласии на США |
| OpenAI (GPT) | США | нет с 01.03.2023 | до 30 дней | только при согласии на США |
| Google (Gemini) | США | нет на платном API | ограниченный срок | только при согласии на США |
| Alibaba (Qwen) | Сингапур, Китай, Германия, Япония, США | нет | срок не указан | требует отдельного согласования |
| DeepSeek | КНР | да, с правом отказа | не определено | не подходит для данных клиник |
| Mistral | Франция / ЕС | нет, кроме opt-in | 30 дней, есть ZDR | допустимо для ЕС |

Источники и дата проверки — в [REPORT.md](REPORT.md#условия-обработки-данных).

## Риски

- Один прогон на модель: разброс между запусками не измерен. Перед пилотом нужен
  повторный прогон финалиста (10 кейсов ≈ 6 ₽).
- C08 (`ok` вместо `insufficient_data`) у GLM требует правки промпта и повторной проверки.
- Оценка на синтетике не заменяет приёмку на реальных обезличенных данных.
- Юрисдикция РФ у GLM зависит от договора с реселлером и должна быть подтверждена
  до обработки данных клиник.
